## 3 数值规格（A1）

- 每项上限由剧本算出：逐幕取该幕选项里该项的最大正增益，累加；场景固定效果也计入。
- 当前值除以该项上限得到比例。上限为 0 的项不参与判定。
- 好结局：线索比例 ≥0.55、关系 ≥0.55、危险 ≤0.45、记忆 ≥0.6，并且到案、拿到两个真相旗帜。
- 坏结局：危险比例 ≥0.7，或关系比例 ≤0.2。
- 其余为中立。
- 硬上限只防溢出：线索 0–200、关系 0–200、危险 0–100、记忆 0–50。
- 这样每加一章，上限自动变大，阈值不用手调。
