# 《暮年武圣》实时生成方案

## 一句话

六十岁的老樵夫伊阳，越老练得越快，在拳头说话的世界里护住孙女、一路往上爬。故事不写死，每一幕由大模型现场生成，玩家选什么，世界就往哪走。

## 一、原著锚点

**体量**：391 章，165 万字。

**金手指**：天命「老骥伏枥，志在千里」。任何功法、技艺，只要去练就涨进度，没有资质门槛、没有瓶颈。进度受寿数加持，六十岁练一遍顶六十遍。年龄就是倍率。

**境界**：气血境九重（练皮、练肉、练筋、练骨、练脏、换血、易经、锻髓、洗身）→ 内气境九重 → 真罡境 → 通玄境 → 宗师 → 武圣。

**舞台**：三木村 → 云纹镇 → 云林县 → 云川府 → 白鱼城 → 青州 → 万妖山脉。

**人物**：姜月欣（孙女，十五岁）、杨惠（邻居寡妇）、周良（猎户）、伊巡（弟弟，镇上富户）、伊展志（侄孙）、孙麻子（村痞）、杨二（村霸）、杨树青（杨大，县衙当差）、赵刚（赤虎帮主）、齐书剑（巡天司总监）、晏无鸢（上司）。

**可用内核**：老年身体、老辣心思、越老越快、护短、扮猪吃虎。这五样是原著的味，生成时必须守住。

## 二、世界怎么运转

三层分工，缺一不可。

**世界层（引擎负责，确定）**
时间、地点、年龄、境界、进度、数值、关系、标记、物品、已发生的事。这些存在本机，每一幕都原样喂给模型，模型不能直接改。

**叙事层（模型负责，自由）**
把当前局面写成正文，给出三个真正不同的选项，并提交一份「状态变更建议」。

**规则层（引擎负责，确定）**
校验模型提的变更：年龄一次最多涨一岁，境界一次最多升一级，关系值夹在正负一百之间，标记和物品去重。合法才写进存档。

这样世界是活的，但不会崩。

## 三、世界书与记忆

**序章**：手写的五幕教学关，交代伊阳是谁、在哪、天命是什么，玩家点几个选择熟悉玩法，然后才交给模型实时生成。序章不消耗模型额度。

**世界书**：按关键词触发的设定条目。提到孙麻子、紫木、青木山，对应的条目才会注入上下文，不占多余的字。常驻的是世界观、境界体系、伊阳和姜月欣的人物卡。

**记忆**：最近六幕的完整输出按对话历史喂回模型，加一份长期摘要。模型是接着自己写的，文风和人设不会每一幕重来。

**角色卡**：每个人物写清身份、性格、说话方式，模型照着演，不能改名、不能凭空造重要人物。

## 四、数值

| 原著设定 | 游戏数值 |
| --- | --- |
| 年龄就是倍率 | 倍率 = 当前年龄，显示在状态栏 |
| 功法进度条 | 当前境界的进度数值 |
| 寿数有限 | 年龄只增不减，一次最多一岁 |
| 秘地加成 | 环境写进世界书，由模型在剧情里体现 |

状态栏显示：地点、年份、年龄、天命倍率、境界和进度。

**天命面板**：点故事页顶部打开，列出天命说明、境界进度条、寿元、危险、银两、威名、任务、持有物品和人物关系。

**系统提示**：正文上方单独一条，只在有值得说的事时出现一发现敌意、功法进度跳升、境界突破、得手东西。给的是情报，不是旁白。

## 五、生成规则（短剧版）

写进系统提示词的硬要求，按红果那种竖屏短剧的路子：

1. 每幕就是一集，正文 200 到 350 字，第一句必须是动作、狠话或冲突，不许环境开篇。
2. 每幕结尾留钩子：新威胁、秘密或反转顶到玩家脸上，没有钩子的一幕等于白写。
3. 打脸不隔夜，每两三幕一次情绪释放：反杀、护短、露一手、当众打脸。
4. 冲突当面顶上来，不绕弯，不写大段心理独白。
5. 台词短、狠、带刺，每句不超过十五字。
6. 六十岁的身体是最大反差，别人当他软柿子，动起手来比年轻人狠。
7. 三个选项是三种活法：狠（当场动手）、阴（记账挖坑）、诈或护（诈底、护人），不许出现软绵绵的「什么都不做」。

## 六、技术

- 模型：DeepSeek，浏览器直连，密钥存本机 localStorage。
- 流式输出，正文边生成边显示。
- 设置页可改接口地址、模型名和密钥，换别的兼容 OpenAI 格式的服务也能用。
- 每一幕的生成日志只在内存里，不落盘。

## 七、后续可加

- 世界时钟：不进主线，时间也会走，杨大在查案、邪教在布局。
- 支线事件：按地点和时间触发的随机遭遇。
- 人物记忆：每个主要人物单独记一份「他对你做了什么」。
- 结局判定：按关系、标记和境界给不同的收尾。
