# 选择幕收尾规范

适用范围：所有 A/B/C 选择幕的正文最后一段。

1. 最后一段必须把决定交回玩家，用问句收尾。
2. 问句前给出两到三种可能发生的事，用「也许、可能、说不准」保持不确定；不直接写选项结果，不暗示哪一个是正确解。
3. 问句要结合当前场景的人物、物件或时间压力，不要每一幕都用同一句「你打算怎么做」。
4. 不替玩家下判断，不写数值涨跌、成功率或结局提示。
5. 选项本身负责具体行动；最后一段只负责让玩家感到「接下来要由我决定」。

示例（序章「拍照」）：

> 她没有催你。摄影师又喊了一声，这回带了点不耐烦。坐过去，合照里就会多留一把空椅；先去接电话，席上这些人会怎么看你，谁也说不准。你先顾哪一头？

检查：`npm run check` 会对未豁免章节强制检查，最后一段缺少问句或第二人称即失败。当前豁免章节列在 `scripts/choice-ending-exemptions.json`，改完一章就从清单删除，检查会立即对新内容生效。
