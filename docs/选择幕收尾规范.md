# 选择幕收尾规范

适用范围：所有 A/B/C 选择幕的正文最后一段。

1. 最后一段必须把决定交回玩家，用问句收尾。
2. 先写角色此刻看见、听见、判断出的东西，让两到三种可能从情境里自然浮现；不复述选项标签，不把 A/B/C 的动作逐条点名。
3. 用具体的人物、物件、时间压力或身体反应推动判断，不要每一幕都用同一句「你打算怎么做」。
4. 不写「也许……也许……也许……」的排比，不用「你先从哪一边下手」这类模板句。
5. 不替玩家下判断，不写数值涨跌、成功率或结局提示，不暗示哪一个选项正确。

示例（序章「拍照」）：

> 摄影师又喊了一声，满棚的人都往这边看。电话还在震，叶小满按在椅背上的手也没有松。你看得出，她在等你先动。你先顾哪一边？

检查：`npm run check` 会对未豁免章节强制检查。最后一段缺少问句、缺少第二人称，或出现两次及以上「也许」，即失败。当前豁免章节列在 `scripts/choice-ending-exemptions.json`，改完一章就从清单删除，检查会立即对新内容生效。
