# 1.1 试玩说明

## 怎么玩

- 开发服务器：http://127.0.0.1:5173
- 重新启动：npm run dev -- --host 127.0.0.1 --port 5173
- 从头开始：浏览器清掉本地存档（localStorage）或开无痕窗口

## 内容规模

- 八章，每章 48 幕、16 个节拍，每三幕一次 A/B/C 选择
- 全书 384 幕，按每幕约 3 分钟计约 19 小时
- 单幕 191–207 字，硬约束：≤400 字、非选择幕 ≥200、选择幕 ≥160

## 三条终局

- 好结局「沙漏停摆」：把方舟和证据带回，公开
- 中立结局「漏沙」：让方舟留下，换倪雨的人撤
- 坏结局「倒转的沙」：放走那条船，证据缺一页

## 数值

- 线索、关系、危险、记忆按剧本自动算上限，判定看比例
- 好结局：线索 ≥50%、关系 ≥50%、危险 ≤45%、记忆 ≥55%，且到案与两条真相
- 坏结局：危险 ≥70% 或关系 ≤20%

## 1.1 补上的东西

- 26 张线索卡全部有来源，每张只在一个场景授予
- 10 枚记忆碎片按章节重新分配
- 推理板 10 条配方全部可解
- 第七章新增 8 处迟回收，回应前面章节的选择
