# 试玩说明

## 在线玩

https://bajibaji.github.io/DancyGame/

## 本地玩

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173。存档在浏览器本地，换浏览器或清缓存会从头开始。

## 规模

- 八章，每章 48 幕、16 个节拍，每三幕一次 A/B/C 选择
- 全书 384 幕，单幕 191–207 字，按每幕约 3 分钟计约 19 小时
- 26 张线索卡、10 枚记忆碎片、10 条推理配方

## 怎么选

- 每次仍然选 A、B 或 C，但同一种做法不会总在同一个位置。部分场景开新局会出现不同做法，部分做法取决于你之前做了什么。
- 选项下方会显示本次行动对线索、关系和危险的影响。第三次及之后连续选增加危险的行动，每次额外增加 1 点危险；选一次不增加危险的行动就会中断。
- 刷新或撤销不会重新抽选项。旧存档可以继续，不必重开。

## 三条终局

- 最后一选决定你如何处理码头上的局面。让方舟留下或放走船，各有固定的后果。
- 选择带回方舟和证据后，调查积累决定最后能否顺利结案：线索和关系至少 50%、危险不超过 45%、记忆至少 55%，还要有到案回执和两条真相。
- 在这条路线里，危险达到 70% 或关系不超过 20% 会得到坏结局；未达好结局要求、也未触发坏结局，则得到中立结局。

## 已知限制

- 结局与尾声里有几段文案还带着旧案人物的称呼
- 多周目没有额外的隐藏结局
