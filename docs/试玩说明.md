# 试玩说明

## 在线玩

https://bajibaji.github.io/DancyGame/

## 本地玩

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173。存档在浏览器本地，换浏览器或清缓存会从头开始。

## 规模

- 八章，每章 48 幕、16 个节拍，每三幕一次 A/B/C 选择
- 全书 384 幕，单幕 191–207 字，按每幕约 3 分钟计约 19 小时
- 26 张线索卡、10 枚记忆碎片、10 条推理配方

## 三条终局

- 好结局「沙漏停摆」：把方舟和证据带回，公开
- 中立结局「漏沙」：让方舟留下，换倪雨的人撤
- 坏结局「倒转的沙」：放走那条船，证据缺一页

## 数值

线索、关系、危险、记忆按剧本自动算上限，判定看比例：

- 好结局：线索 ≥50%、关系 ≥50%、危险 ≤45%、记忆 ≥55%，且到案与两条真相
- 坏结局：危险 ≥70% 或关系 ≤20%

## 已知限制

- 结局与尾声里有几段文案还带着旧案人物的称呼
- 多周目没有额外的隐藏结局
