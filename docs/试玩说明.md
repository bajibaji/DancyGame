# 试玩说明

## 本地试玩

运行 `npm install`、`npm run dev` 后打开 http://127.0.0.1:5173。存档保存在浏览器本地；清站点数据、换浏览器或重新开始会影响原进度。

在线地址 https://bajibaji.github.io/DancyGame/ 以已发布版本为准，本轮本地修改尚未发布。

## 当前范围

- 当前版本 1.5.5，开放序章与第一至第五章，共 438 幕、146 处 A/B/C 选择。
- 第五章结束显示「敬请期待」，进度保留，可查看档案或返回标题。
- 第六章以后剧情、题目与未开放档案暂时隐藏，原稿与后段旧存档保留。
- 目前没有首次完整结案。全篇 16 小时仍是长期目标，真人首玩时长未实测。

## 选择与查证

每次保留三个行动，位置随周目变化。部分场景有情境备选或前序行为解锁行动；同周目刷新和撤销不重新抽牌。行动卡只显示行动与情境，不显示数值涨跌。已开放五章的选择幕最后一段都会把决定交回玩家，给出两三种可能，但不会说明哪一种更有利。

## 调查状态

顶部显示线索、关系、危险三项状态。新开一局时三项先显示「？？」，状态词和进度条暂不显示；对应数值第一次变化后，该项才展开百分比、状态词和进度条，未变化的项继续隐藏。百分比按当前章节及之前可取得的材料量计算，不是全篇进度。重新开始会重新隐藏。

关键材料不因选错永久丢失。推理题在取得材料后开放，答错提示核查方向，也可暂时跳过继续故事。已取得结果在对应场景回收。

## 旧存档

开放章节旧进度继续保留，已越过新增取证段落的未结案档补齐必要材料，不重新结算选择或分数。已在后段的档暂显示「敬请期待」，原位置和已有资料保留，后段材料仅隐藏显示。

## 验证边界

自动检查验证引用、路径、材料时点和存档，浏览器检查验证实际操作。二者不能代替原著新手盲玩、剧情理解与时长验收。
