# 更新记录

## [0.2.1] - 2026-11-23

- 阅读设置新增「特大」字号。手机正文约 26px，剧情选项同步放大；原有字号和进度存档不变。

## [0.2.0] - 2026-11-23

### 新增

- 电脑端改为桌面工作台布局：剧情页左侧阅读、右侧常驻调查状态与快捷入口；档案库左侧分类导航、右侧内容；推理板左侧题目列表、右侧作答；手机保持原有单列布局。
- 正文与标题在电脑上按舒适阅读宽度排版，主按钮和正文同时放大。

### 变更

- 选择后的数值变化改用绿/红光效反馈，不再显示具体增减文字；撤销按钮固定在右下角，正文不会因提示出现而移动。
- 线索在电脑上三列展示，人物与记忆双列展示。
- 设置页双列为阅读与存档、动效与关于两组。
- 结局页正文按舒适宽度居中，标题页主按钮加宽。

## [0.1.1] - 2026-11-23

### 新增

- 版本号管理：package.json 为唯一来源，构建时注入应用，设置页「关于」显示当前版本。
- `npm run check` 校验版本号格式，并要求 docs/CHANGELOG.md 存在同版本条目。

### 变更

- 推理板改为按章节解锁的推理题：6 道配对、4 道矛盾判断，答错逐步保底，成功后解锁补充材料。
- 推理板成为档案库第一个标签页；修复分段控件宽度、圆角与语义配色。
- 关系上限 30、危险上限 20；线索新增损失来源，负关系加重；好结局阈值为线索 18、关系 18、危险 14、记忆 8，坏结局为危险 16 或关系 9。
- HUD 移除记忆数值，三值按状态变色并显示数值变化浮字。
- 存档版本升到 2，旧档关系值 ×2 迁移。

## [0.1.0] - 2026-11-22

- 首个公开版本：完整七章剧情、三结局、档案库、推理板与移动端界面。
