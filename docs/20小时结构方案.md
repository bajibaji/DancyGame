# 20 小时结构方案 v3

版本：2026-11-24。相对 v2 的改动：加回两条世界线，以好坏为轴，可来回摆荡；信息永不丢失。总时长、单幕字数、选择密度、3 个结局不变。

## 1. 骨架

20 小时 = **240 个节拍**；一个节拍 = 3 幕 + 1 次选择 = 5 分钟。720 幕，15 章，每章 16 个节拍、48 幕。

## 2. 散雾引擎

一条真相，一层层散。

1. 每个节拍改变一次解释：补一块拼图，或推翻玩家原来的以为。240 个节拍 = 240 次认知变化。
2. 每章一次翻案。15 章 = 15 次「原来是这样」。
3. 每部散一层大雾：案件层 → 旧案层 → 身世层。

## 3. 两条世界线：顺线与逆线

世界线不是剧情分叉，是**这个案子在你手里是顺的还是逆的**。

| 线 | 状态 | 同一幕的写法 |
| --- | --- | --- |
| 顺线 | 手续批得下来、证人肯说、有人替你签字 | 门能推开，问话有回音 |
| 逆线 | 手续卡住、证人反口、队友被调走 | 门推不开，但你知道门后有什么 |

两条线看到的信息完全一样，区别在于**能不能把它变成能站住的证据**。

### 摆荡规则

- 内部记一个「局」值，范围 −6 到 +6，开场为 0。
- 每次选择推动 ±1 或 0；连续两个节拍没有同向推动，局值向 0 回一格。
- 局值 ≥ +2 进顺线，≤ −2 进逆线，中间为悬线（用主版本正文）。
- 跨线那一刻插入一幕「翻面幕」，约 300 字，让玩家明确感到局变了：一场雨、一次调令、一个原本该来的人没来。
- 翻面有冷却：切换后两个节拍内不再切回，避免来回抖。

一周目预计翻面 12–18 次。**可以反复摆荡**：顺线掉到逆线，也能靠后面的选择爬回来。

## 4. 信息永不丢失

- 所有材料都进档案库，两条线都拿得到。
- 材料分两种状态：**可用**（能提交、能撞证）与**待证**（知道，但缺一道手续或一个人）。
- 逆线里多数材料是「待证」。把「待证」变成「可用」需要多走一到两个节拍——**增加工作量，不减少信息**。
- 撞证失败不销毁材料，只把两条材料标回「待证」。
- 任何一章节拍走完，本章的关键材料必然到齐。

这条规则是硬约束，写进自动校验：每个节拍结束时，关键材料数不得低于本章下限。

## 5. 选择三类

| 规格 | 次数 | 改什么 | 推动局值 |
| --- | --- | --- | --- |
| 问谁 | 120 | 从谁嘴里拿材料、欠谁人情 | ±1 |
| 查什么 | 80 | 手里是哪条证据链 | ±1 或 0 |
| 信谁 | 40 | 章末翻案从哪个版本落地 | ±2 |

三个选项永远通向同一真相。选错不丢信息，只把材料变成「待证」，并让局值往逆线走。

## 7. 三个结局 × 两条线

结局由最后怎么处置真相决定；落在哪条线上，决定尾声的写法。

| 结局 | 顺线收束 | 逆线收束 |
| --- | --- | --- |
| 交出 | 案子全部到案，名字补齐 | 到案一部分，剩下的名字你替他们记着 |
| 换人 | 人回来了，缺一页卷宗 | 人回来了，但没人承认那份材料 |
| 带走 | 你懂了，没人需要你作证 | 你懂了，只有你自己知道 |

三个结局各约 2000 字，两种收束各写 800 字变体。

## 8. 写作契约

- 一幕只做一件事，250–380 字，允许 20% 的短幕。
- 动作 → 信息 → 钩子；最后一句要改变判断，不只是想看下一页。
- 顺逆双版本的幕控制在 30% 以内（问话、搜查、报批三类）；其余用一两句变体交代在场人和称呼。
- 禁止幕末总结句、旁白解释动机、连续两幕同场景同时间。

## 9. 成本

| 项目 | 数量 |

| 主干正文 | 25 万字 |
| 双版本幕（约 200 幕） | +5 万字 |

| 翻面幕（16 幕） | 0.5 万字 |

## 10. 这些约束能不能完全执行

| 约束 | 能否 | 说明 |
| --- | --- | --- |
| 20 小时 / 720 幕 / 240 次选择 | 能 | 靠节拍表和字数校验硬卡 |
| 单幕 ≤400 字、3 幕一次选择 | 能 | 写进测试 |
| 好坏双线来回摆荡 | 能 | 局值 + 阈值 + 冷却，需要改引擎状态 |
| 选错不丢信息 | 能 | 档案全收 + 待证/可用两态，写进校验 |
| 3 个结局 | 能 | 各两条收束变体 |
| 每 3 幕一个「改变解释」 | 能，但要人写 | 这是写法，不是规则，靠样板验收 |
| 读起来像人写的 | 不能保证 | 只能靠样板 + 盲测迭代，不能一次到位 |
| 20 小时不注水 | 不能保证 | 需要每部写完做一次删减，去掉为凑时长写的幕 |
