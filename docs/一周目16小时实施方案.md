## 1. 要交付什么

**让没读过原著的玩家，从新游戏查到第一次结案，典型用时约 16 小时，并且说得清自己是凭什么查出来的。** 本稿按 **14 个可玩章节（1 个序章 + 13 章正篇）** 规划。保留现有案件主干，不另开独立大案；把原来略过、只由队友汇报、或几条调查线挤在一起的段落，拆成玩家可以亲自查完的章节。

- **计入**：首周目正常阅读、读证据、比较说法、做决定、推理、体验选择后果，直到首次结案页。解锁或使用剧情自然给出的提示也算。
- **不计入**：离开游戏、休息、切出页面、卡死重试、演示计时、专门收集全结局、读攻略、反复刷分支。逐字播放可随时展开，不能成为达标条件。
- **目标人群**：能正常阅读中文、没看过原著、没玩过本作的玩家。不是速通时长，也不要求每个人都玩满 16 小时。
- **已确认的验收口径**：上述新玩家从新游戏到第一次结案的有效用时中位数为 **15–17 小时**，同时通过第 5 节的剧情理解和选择后果验收。只达到时长不算通过。
- **保护玩家原有体验**：保留三个 A/B/C 行动位置、后台数值与存档；不在选项卡里显示数值涨跌、概率、结局分或最优提示。行动风险靠现场和人物反应表达。
- **不做**：整章灌水、定时解锁、必须回档、必须把档案全点一遍、选错罚时间、为了重复游玩锁结局、用配音或动画延长时间。没有改善理解或改变行动的内容不列入有效时长。

每个调查单元开稿前都有一条可追溯记录：**原文章段 → 原著事实 → 改编保留/合并/另作 → 玩家当时已知 → 新材料 → 判断变化 → 后续回收**。在游戏里，证词、推测、证实要分开写。身份没确认就用编号或关系描述；第二具遗骸的解释不提前写进公共正文。旧档案与结局也一并对齐人名、时间和地点。

记忆采用同样的检查：**当下触发物 → 记起的具体事实 → 回到现场 → 验证或修正原判断**。童年印象可以给方向，不能自行作为定案证据。缺当下回收的记忆删掉、合并或延后。

### 调查单元的最小交付

1. 给一个要解决的问题，例如「证人说亲眼见他回去了，他当时究竟能看到哪段路？」不是「打开档案」这种操作任务。
2. 提供至少两类可感知的信息来源，如证词与记录，并让玩家看出两者互相支持还是冲突。
3. 玩家亲自选怎么核对、向谁复查或接受哪一种暂定解释。结果必须能说明为什么改判，不能由队友在场外把答案查完。
4. 出现一次可观察的局面变化，再给下一步。比如证人愿意留下补录、证词要另行核验，或某份材料从「旁证」变成「不能支持原说法」。
5. 选错仍能推进。第一次提示指向材料，继续卡住给解释或替代取证。真相必须有公平来源；缺证影响结案和旁支后果，但不能让存档无路可走。

以开场为例，可拆成两组调查：**找人**（先认识伴郎、听到相互不符的最后目击、补查来源才改变判断）与**现场交接**（区分发现物、传言、身份待确认状态，给第一章留下能查的材料）。样板只完整制作序章；第一章先接到一个可操作的开场，用来验证交接与续读，不计入序章计时。试玩重点是玩家能不能说清两组问题的区别，以及到第一章为什么要接着查。

### A/B/C 与后台数值

- 字母是位置，不是稳健、冒进、折中三个固定职业。行动可来自查物、复问、请当事人补充、请求同伴协助、选择证据提交顺序等。同一选择至少改变**谁开口、先取得什么、谁承担后果、后面怎样验证**之一。仅改语气的不占一个选项。
- 例：目击时间对不上时，可以「请叶小满在合照里指出最后见到人的位置」「对照席面记录和照片顺序」「先听送客人讲完，再拿两条说法逐项核对」。三种手段有不同的先得信息和回访条件；关键进展可经其他途径补齐。例子是样板设计，不是已实现剧情。
- 一般选择要在下一幕看到即时后果；重要选择至少还有一次后续回响（证人态度、材料顺序、不同复核、尾声之一）。编剧在表里写触发、即时反馈、后续兑现，关卡验证时逐条看，不接受只改成另一段总结。
- 随机只在**当前情境成立、作用相当**的候选里做：位置可调换，已取得线索或前序行为可解锁备选。每周目稳定，刷新、读档、撤销不能刷出另一张牌；关键证据、唯一回收和终局决策不交给抽签。
- 数值服务于真实局面，不把长期收益叠满当成长。扩写会改变累计量，必须重新跑线索、关系、危险、记忆和顺逆线分布；先验明白不同玩法为何分流，再调整阈值。选项卡任何状态、任何屏幕都不展示数值变动；不新增同义的好坏评分提示。保持现行不掉线索、不因试错而永久失去关键材料的约束。

### 内容与实现的共用约定

- 沿用仓库剧本硬约束：普通幕正文 200–400 字、选择幕 160–400 字、每三幕一个选择节拍；A/B/C 即时后果互不相同且各不少于 40 字。需要顺逆双线的幕继续写双版本。伏笔至少两次铺垫、一次误读、一次回收；连续三个低张力节拍要检查，每章至少一个峰值。若样板证明规则妨碍体验，要单独说明理由并获批后才能同时改规则和校验，不能为通过测试静默放宽。
- 写稿清单至少含章节、单元、场景 ID、入口、出口、人物、当时可知事实、证据来源标记、后果、回收、时长和已有场景的替换关系。先填清单再写正文。实现优先沿用现有场景、线索、推理题、回收文本和结局数据；只有样板做不到的互动才加能力。
- 拆章时为每处交接写清「上一章实际交出的事实与材料、下一章开场能用什么、遗漏材料到哪补」。章节顺序以同一份目录为准，展示编号与稳定场景 ID 分开；检查推理题解锁、剧情提示、故事校验与模拟路线步数是否仍依赖旧的八章名单或长度。终局规则跟着终局场景走，不跟着以前显示的章号走。
- 旧场景、卡片、旗标 ID 能保留就保留，不能沿用则列出迁移表与兜底落点。旧版中途档不能跳进拿不到必需材料的位置；已结案档不能被自动重开；续读、档案返回和撤销要保存进度与周目随机种子。
- [剧情跳转测试](../tests/story-data.test.ts)、[选项测试](../tests/choices.test.ts)、[存档测试](../tests/game-store.test.ts)及[剧本校验](../scripts/check-prose.mjs)是起点。当前校验中的文件排列检查不等于真实路线检查；扩写后需按实际跳转检查选择间隔、前置证据和回收。设计两条轨道：先把内容骨架与样板通过，再扩交互和全章，不先造一套大系统。

## 5. 验证怎么做

### 自动检查：证明能查、能走，不证明好玩

- `npm.cmd run check`、`npm.cmd run build` 集中执行。跑全图：所有首次通关正规路线按序经过 14 章，每条章界有直接验证；无坏引用和剧情死路，三类结局均可达。每章首个推理题和关键证据要核对解锁时点，必要证据不能永久缺失；路径实际选择间隔、提醒点、普通与双线正文都查。
- 模拟至少 1,000 个已记录的周目种子，另加指定保底、错判、末选、极端危险和回访路线。输出具体覆盖、同一路线去重文本量、选择数、调查单元数、材料来源和结局。种子抽样不代表穷尽，关键条件另写定向用例。
- 同一周目刷新、旧档迁移、撤销后仍可继续；至少覆盖旧八章中途档、拆分章界前后档、旧终局选择档、已结案档。切走档案再返回不会丢线索或重复发放。选项卡文字回归覆盖普通、变体和随机机会，确认无「关系 +1」之类数值变动文本。结案复核人物、材料归属和去向。
- 桌面、手机各实际操作开局、跨章、查档/返回、提示、存档/续读和结案；至少跑一条正常流程，至少一条错判后补查的流程。录关键截图及版本，不把无界面脚本当浏览器试玩。

### 真人盲玩：决定能不能叫 16 小时

1. 正式候选版建议 **至少 8 名完整首玩**，同一版本，覆盖快慢阅读习惯与桌面、手机；看过原著的人可另做对照，不并入主样本。退出一并记录退出章节与原因，不因为人没通关就从体验报告里抹掉。收集时长和阶段数据前先告知玩家，不采集与验证无关的信息。
2. 分章记录开始、结束、有效阅读、选择、调查、停顿和提示使用。暂停、切出、休息从总时长扣除；长静默先由测试员与玩家在分段结束后核实是阅读还是离席，不能按是否点击简单切掉。试玩期间不发答卷教人查案；每章结束再回问关键因果和卡点，问答时间不计入。
3. **推荐放行线**：有效首通中位数 **15–17 小时**；至少 **6/8** 落在 **13–19 小时**，扩样时至少 75%。没有必须靠外部攻略、测试员干预或重新开局才能完成的步骤；若至少两人因同一处误解或疲劳退出，先修再验，不用剩余样本时长压过这个问题。样本量是发布门槛，不是全体玩家时长保证。
4. 理解验收：至少 75% 首玩者能在不提示情况下解释四项中的三项：婚礼案发现和身份确认的先后、竖井和山灼哪些事实相关、关键记忆如何改变一次核验、终局为什么得到当前结果。每章另用调查单元预先写的复述题检查，答案按证据与因果给分，不考背名字。
5. 取舍验收：每章抽两处在场景表标记的关键选择，至少 75% 受测者能说出所选行动想获得什么，并指出一处后果或延迟兑现；不能只回答「看起来加分」。错过备选、没读完旁支、用了合理提示的玩家一样能完成主线。

处理偏差：**时间短但理解好**，先增加缺失的查证和人物反应；**时间够但理解差**，拆开揭晓、补证据出处和可用提示；**时间长且疲劳**，删重复问询、减少同义选项、合并无因果停顿。测试记录必须写清慢在哪里，不能只靠时长判断好坏。时间过线、理解或取舍没过，仍不发布「16 小时」说法。
