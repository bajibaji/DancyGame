## 维护约定

1. 改动一个主决断时，同时写清眼前动作、失去的机会、下次读到后果的地方。抗命不能用「选择更勇敢」代替现场代价；遵照程序不能用「无事发生」代替取证变化。
2. 角色对白标注是亲见、转述、推测还是供述。线索卡只记当时拿得到的材料；推理板只给交叉校验方向，不负责解锁主线真相。身份名以本表的揭晓幕为界。
3. 到案、记忆、岗位和两人关系分别写。选了家属并不保证好结局；优先救人就算暂未抓到人，也不是失败。保留存档 ID；不把旧选项的字母解释成新版行为。
4. 再加一条原著锚点时，写章号、该段功能、是否已写入游戏、相应场景 ID。记录判断需要哪份证据，不入库原文或长对白。
