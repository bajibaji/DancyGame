## 需返修的问题

### R01 / P1：档案内容与授予场景不对应

`ch01.json:204` 的账本只写金额不大、付款人空白，却在该幕授予 C04「八万元流水」，档案已断言杜衡支付八万元且备注货款。`ch01.json:613` 授予的 C08 已确认钥匙对应桑塔纳、闻茉用车和二人退学，当前正文只到涂改名单与待核姓名。`ch02.json:101` 在账目页授予 C06「孔云镇锁环」，没有空棺、锁环的取得过程；`:371` 在塑料布场景授予 C07「竖井三具遗骸与钥匙」；`:385` 在厂徽场景授予 C02「袁衷指甲里的玻璃纤维」。卡片定义在 `src/content/clues.json` 第 3、5、7–9 行。

影响：打开档案会得到正文从未证明的结论；沿用旧 ID 使读档仍能加载，却失去证据语义一致性，并影响后续推理。

修复目标：逐卡确定应保留的案件事实，补足取得、检验、确认的场景，或调整授予点。不要直接重定义旧卡 ID 而不检查旧存档和全部配方。复验每张卡的首次可知时点及新档、旧档来源。

### R02 / P1：人物、选项和进度提示仍混用旧稿

`ch01.json:423` 将老厂特勤写为谢惊屿，`:458`、`:473` 的进度仍写战远；`src/content/opportunities.ts:74` 附近的随机行动也继续让战远操作封条。人物库定义该角色为战远，第二章直接沿用战远。另在 `ch02.json:97` 的账目问题下，三项仍是罗家案卷、守墓人和黄纸比对，前文没有相应材料或调查缘由。

影响：同一人无说明换名，随机选项与正文出场者不符；账目调查突然进入墓地案，玩家无法理解行动依据。

修复目标：统一改编人物映射，成组审核正文、三个行动、随机替代、即时后果和进度。墓地选项需要明确铺垫或迁到适当调查单元。

### R03 / P1：三具遗骸失去实际发现过程

第一章仅写井口、踏板和钥匙，第二章改为排水沟、塑料布与厂徽，但 `ch02.json:407` 已写「三具遗骸里两个名字对上了」，`:473`–`:499` 又让玩家决定三名死者身份比对或问杜衡井底三个人。此前没有发现、提取或数量确认；卡片 C07 提前替正文宣布结果。

影响：重现玩家此前指出的突然死亡、调查结论跳跃，调查样板的核心因果不成立。

修复目标：先亲历发现、分号、提取和送检，再讨论身份与口供；未比对前不靠厂徽直接对人名。

### R04 / P1：用重复句补足字数，且污染现场

`scripts/pad-prose.mjs:4`–`:29` 用 12 句固定文字循环补到长度下限。实际第二章 27 幕中 22 幕包含这组句子，共 829 字符，约占本章正文 15%；全篇 155 幕含此组句子。`ch02.json:591` 在湖边货车旁写「灯管嗡了一声，屋里没人抬头」，`:609` 湖边出现门缝和桌角，`:609` 之后的选择正文又出现墙钟和走廊。

影响：长度检查通过却增加重复和空间矛盾，违背有效扩写要求。

修复目标：清除机械补句，按当前人物、物件和调查问题补实质内容；不再通过运行填充脚本达标。复验应检查跨场景重复段与场地矛盾，保持原有长度约束。

### R05 / P2：分支结果被下一幕覆盖

`ch02.json:342` 的行动只用相机拍洞内塑料布，或选择等待战远；下一幕 `:367` 不分路线直接写「塑料布装进证物袋」。已通过实际状态仓库选择拍照路线复现，相机照片与已取实物连续显示。同幕还从登记本直接推出「封条被撕在次日凌晨」，前文只有发现撕口，没有确定发生时刻的证据。

影响：选择失去真实区别，未取得材料被写成已取得，时间判断无来源。

修复目标：用已存在的旗标、正文变体或明确的后续统一提取交代过程；取得照片与实物必须区分，准确时点需要来源。

### R06 / P2：调查时间与场景时间不一致

`ch01.json:336` 给出的 11:42 和 11:44 相差两分钟，标题、问话、后续行动却反复写四分钟。`ch02.json:579` 连夜路线已在天未亮到湘湖，紧接 `:591` 又写傍晚、离天黑还有一阵；未明确隔了一天或再次到场。

影响：玩家依据错误时间窗查车辆，路线成本与后续时段脱节。

修复目标：为各段录像明确开始、结束和断点长度；按实际出发、到达和等待顺序统一时间，不能仅换界面时间标签。

### R07 / P2：章界目前只是顺序拆分，未对齐调查单元

第一章 `c0108c` 明说选择决定下一章手中材料，第二章 `c0109a` 转去战远和录像，没有回收学校线；该选择目前只保留一次即时后果。第三章名为竖井，实际入口是山庄，主体包含乐园、排班和后山；第四章已经演完向死而生及背尸揭露，第五章才显示「背尸」。因此可以确认连续进入 14 章，但尚不能确认达到方案要求的独立调查问题、出章所得和下一章接手点。

修复目标：先画现有事实、材料和揭晓的顺序，再按调查目标分配边界；保留稳定场景 ID。每条章界写明交出什么、接手什么、缺材料到哪补。

### R08 / P2：旧断言静默跳过，无法保护拆章验收

`tests/story-data.test.ts:10` 用第四章幕数至少 40 判断内容完整，新第四章只有 27 幕；`:149` 一带又依赖不存在的 `c0408`、`c0609`、`c0708` 等旧 ID，随后提前返回。因此「关键档案不提前入档」测试名仍显示通过，实质断言未执行。现有推理测试只检查材料齐全和章节合法，未沿实际授予路线校验卡片内容和复核时点。

修复目标：按稳定事实场景而非幕数或旧短 ID 定位，避免无声返回；添加真实路径的前后时点断言，覆盖新章界和必要证据的各策略保底。
