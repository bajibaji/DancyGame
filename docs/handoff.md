原著底本为 UTF-8：`D:\Downloads\《空相沙漏[刑侦]》作者：初禾二.txt`。本机有 `book/chapters_index.json` 与 `book/parts/`，不入库、不打包。`.workflow/` 是历史研究归档，内有已弃用的角色名和 AI 接入设计，不能覆盖当前知识库。旧版交接及完整背景仍可从基线 `4f3adc2` 查阅。

## 当前规则

- 全图 79 幕、26 组 ABC、78 个选项。第七章的港区与边境各有三幕，一周目实际走 76 幕、25 次抉择。
- 序章把第一组选项从 `p03` 移至 `p01`：第一幕决定要不要进婚礼合照。场景编号不变，警戒线 `p07` 与第一章 `c0107` 回收实际选过的合照支线；旧档没有合照旗帜时使用共用正文。
- 选择写入当时的动作、目标场景和即时后果；`resolveSceneBody` 按「即时后果、命中旗帜的回收、默认或替代正文」合成单场景和连续模式的文本。改动一处主决断，同时核对后续场景、档案卡和结局；不要把没有拿到的材料写回共用场景。
- 第二章 `c0206a` 新增杜衡对质，`c0206b` 继续承接旧档和三种对质结果。第三章 `c0308`、`c0309` 根据 `c0304` 的选择写战远的行动。关键场景读完后显示「调查进展」，选择对应的回执随历史保存。
- 档案库有 26 张线索卡、10 枚记忆碎片，人物按已读正文中的姓名开放。推理板有 10 道章节推理题（6 道配对、4 道矛盾判断），答错先提示方向、两次后逐项保底；正确只加一次 2 点线索，并在后续场景解锁一段补充材料。D10 和 D03 在第二章对应幕开放两份可选材料，其余题目的材料分别挂在第一、二、三、五、六章末。
- `jiangjia.save.v1` 保留已结算选择和当前场景，`jiangjia.settings.v3` 独立保存阅读设置。选择后停在下一幕时有 5 秒撤销，可一起回滚数值、旗帜、档案、阅读记录和人物；刷新没有撤销窗口。
- 旧存档保留历史选项的标签，不把旧字母套成新版后果。早于 `c0609` 的旧笔记本和记忆真相标记在读档时移除，至该幕重新入档。旧留港档未做终局决定时回到港区，已做决定的不改路线。
- 危险 ≥16 或关系 ≤9 判坏；线索 ≥18、关系 ≥18、危险 ≤14、记忆 ≥8、确认到案并取得两个主线真相旗帜才判好；其他判中立。三种结局分别写案情、记忆、感情与工作。岗位选择在结局之后，不改抓捕结果或关系答复。

## 运行与验收

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run check
npm.cmd run build
```

- 本机入口：[http://localhost:5173/](http://localhost:5173/)。切换到修订前的存档可以继续，验收新版节拍请从标题页重新开始。不同地址（如 `localhost` 和 `127.0.0.1`）各有独立存档。
- 2026-11-23：类型检查、ESLint 和 Vitest 通过，6 个测试文件、71 项测试。覆盖 5,000 条固定种子路线、剧情图、对质回收、补充材料、存档与撤销。生产构建通过，仍有单个 JS 分包超过 500 kB 的体积提醒。
- 本轮在 375、393、430px 的 Chrome 触屏视口分别从序章走到第四章入口，每条经过 38 幕、12 次抉择。验证杜衡对质三路、战远三种回收、调查进展、撤销、刷新、旧 `c0206b` 存档续玩，以及推理补充材料的键盘展开与收起。覆盖单场景和连续阅读两种模式。
- 盲玩验收记录玩家用什么证据让谁改口，战远因哪次判断主动做了什么，以及哪件事让玩家愿意翻到下一章。
